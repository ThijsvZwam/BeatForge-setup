# ¦ BeatForge Setup

Quick installer for **BeatForge**, a Lua modcharting library for Beat Saber

---

## Install

Run this inside **Windows Powershell**:

iwr https://raw.github.com/ThijsvZwam/BeatForge-Setup/main/install.pst | iex

---

## After install

Use this command in any Beat Saber map directory:

bf_setup

---

## Output

Beat Saber map folder:
- beatforge.lua
- script.lua

---

## Requirements
- Windows PowerShell (not Git Bash)
- Beat Saber 1.29+ (v3 maps)
